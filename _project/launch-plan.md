## The Steps

**1.** [ ] Finish website — content, colors, layout approval

**2.** [ ] Finish PDF — reflect real beliefs and real experience, not generic advice

**3.** [ ] Buy domain + DNS setup
   - Target domain ideas: `stopoverthinkingYourirons.com`, `simplygolf.com`, `realgolftips.com`
   - Buy at: namecheap.com (~$12/year)
   - GitHub Pages DNS records to add:
     ```
     A → 185.199.108.153
     A → 185.199.109.153
     A → 185.199.110.153
     A → 185.199.111.153
     ```
   - Then: Settings → Pages → Custom Domain in GitHub

**4.** [ ] Open TikTok account
   - Set up profile and bio
   - Add website link to bio from day one
   - Account name ideas: `@stopoverthinkinggolf`, `@simplygolf`, `@realgolftips`

**5.** [ ] Open Gumroad account
   - gumroad.com — free to sign up
   - Upload PDF, set price at $9.99
   - Get checkout link for PDF
   - Note: Bundle (PDF + Video) added later when videos are ready
   - Gumroad takes ~10% per sale

**6.** [ ] Provide Gumroad links to Claude — buttons updated same day
   - PDF link: (paste here when ready)
   - Bundle link: (paste here when videos are ready)

**7.** [ ] Go live — confirm domain is working, site looks correct

**8.** [ ] Make a test purchase
   - Buy your own product end to end
   - Confirm payment processes
   - Confirm PDF download delivers correctly
   - Confirm receipt email arrives
   - Fix anything broken before telling anyone

**9.** [ ] Share with 5–10 golfers you know
   - Friends, club members, anyone who golfs
   - Ask for honest feedback — what's confusing, what's missing
   - Collect first testimonials here

**10.** [ ] Make 5–10 TikTok videos before posting the first one
   - Build a content buffer
   - Don't feel pressured to post daily from day one

**11.** [ ] Start posting TikTok content
   - Organic first — no paid ads yet
   - One tip per video, 30–60 seconds
   - Your face, your voice, your story
   - See Marketing Plan for video ideas

**12.** [ ] Submit site to Google Search Console
   - Free — takes 5 minutes
   - Gets site indexed by Google
   - URL: search.google.com/search-console

**13.** [ ] Paid TikTok ads
   - Only after organic content is working and getting views
   - Use best-performing organic video as first ad

**14.** [ ] Paid Google ads
   - Only after you have testimonials and proven conversions
   - Target keywords: "how to stop slicing irons", "high handicap golf tips", "simple golf swing"
